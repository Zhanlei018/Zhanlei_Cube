# cube/input —— 拾取与拖动解析

职责：把"鼠标像素坐标 + 拖动"翻译成 `Move`。这是全项目最容易翻车的一层。

## picking —— 屏幕坐标 → 命中面

1. 像素坐标 → NDC（**y 要翻转**：`ndc.y = 1 - 2*mouseY/height`）
2. 用 `inverse(proj * view)` 反投影出近点、远点
3. 射线起点 = 相机位置，方向 = normalize(far - near)
4. 与魔方外表面（[-1.5, 1.5] 的立方体，6 个面）求交，取 `t` 最小的正交点
5. 得到交点 P、面法线 N、格坐标 `round(P / pitch)`

**不需要**遍历 26 个小方块的 AABB，太浪费。

调试里程碑：先不做拖动，只把悬停命中的小方块高亮出来。
这一步过了，说明射线、坐标系、投影全对。

## drag —— 命中面 + 拖动向量 → Move

1. 按下时锁定 `P0` 和法线 `N`（拖动全程 N 不变）
2. 松开（或位移超阈值）时，用**同一平面**求交得到 `P1`
3. `D = P1 - P0`，去掉法线分量：`Dt = D - N * dot(D, N)`
4. 取 `Dt` 三个分量里绝对值最大的轴 → `dragAxis`
5. **旋转轴 = cross(N, dragAxis)**，取整归一化
6. **旋转层** = `layerOf(P0 格坐标中对应 rotAxis 的那个分量)`
7. **方向符号** = 先按右手定则取 +1，然后实测，错了就整体取反

## 致命陷阱

**不要拿屏幕空间的拖动向量去叉乘世界空间的法线。** 必须先把拖动投影到被拖的面上，
否则视角一斜结果就飘。上面第 3 步就是干这个的。

## 状态机（防止手抖连击）

```
Idle ──mouse down──▶ Pressed ──位移 > 8px──▶ Dragging ──mouse up──▶ 提交 Move ──▶ Idle
```

- 位移不足阈值 → 当作点击处理（或忽略），不产生 Move
- 一次拖动只允许产生一个 Move
- 接缝上两轴分量接近相等会抖动：取最大分量，平局时固定优先某轴
