# cube/math —— 数学薄封装

职责：整数旋转矩阵、格坐标 ↔ 层号的换算、以及不依赖 GLM 的小工具。
**本目录禁止 include 任何 OpenGL / GLFW 头文件。**

## 你需要在这里写的东西

| 函数 | 说明 |
| --- | --- |
| `intRotX/Y/Z(int quarterTurns)` | 返回 3x3 整数旋转矩阵，只含 0 / ±1，零浮点误差 |
| `layerOf(int coord)` | 格坐标 -1 / 0 / 1 → 层号 0 / 1 / 2 |
| `axisIndexOf(char axis)` | 'X' / 'Y' / 'Z' → 0 / 1 / 2，用于下标访问 |

## 关键约束

- 逻辑层一律用 `int`，**永远不要**让浮点进入 cube_core
- 旋转矩阵必须走右手定则：绕 +X 正向转时 +Y → +Z
- 行列式必须是 +1（是旋转不是镜像）。写错的话小方块会翻面，颜色全乱
