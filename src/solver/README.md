# cube/solver —— 打乱与复原

职责：产生 `std::vector<Move>`。**它不知道 OpenGL 的存在**，输出喂给动画队列即可。

## 阶段 6：打乱 + 历史逆序复原

- 打乱：18 个基础 Move 里随机取 25 个。约束：不连续同一面、避免 `R L R` 这种三步循环
- 复原：维护 `vector<Move> history`，逆序遍历，每个 Move 取逆（轴不变、层不变、dir 取反）

这个方案保证**每一步都是真实转动**，不是换颜色，用户可以看着它转回去。

## 阶段 7：任意状态求解

**路线 A（推荐先做）—— 逐层法 Layer-by-Layer**

底层十字 → 底层角块 → 中层棱块 → 顶层十字 → 顶面朝向 → 顶层角块归位 → 顶层棱块归位。
纯逻辑、无搜索、可单元测试，可以直接在终端里跑。写起来长，但一定能做出来。

**路线 B（进阶）—— Kociemba 两阶段**

建剪枝表（几十 MB）、坐标编码、pruning 索引。求解极快（< 20 步），但工程量大得多。
等 A 跑通再考虑。

## 注意事项

- 不要在渲染循环里同步求解 → 会卡帧。求解器只输出 Move 列表
- 逐层法建议先在终端里调通（配合 tests/），再接 UI
